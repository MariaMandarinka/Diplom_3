# Дипломный проект: Автоматизация тестирования сервиса Stellar Burgers

Реализация автоматизированных UI-тестов для веб-приложения космической бургерной **Stellar Burgers** в рамках дипломной работы курса «Инженер по тестированию» от Яндекс Практикума.

## 🚀 Стек технологий
* **Python** (версии 3.10+)
* **Pytest** — тестовый фреймворк
* **Selenium WebDriver** — инструмент для автоматизации действий в браузере
* **Allure Framework** — генерация визуальных интерактивных отчётов о тестировании
* **Паттерн проектирования:** Page Object Model (POM)

---

## 🛠 Реализованная функциональность
Проект включает в себя автоматизацию ключевых пользовательских сценариев, разбитых по двум основным блокам:

### 1. Основная функциональность Конструктора
* **Навигация:** Проверка успешного перехода по клику на разделы «Конструктор» и «Лента заказов».
* **Карточка ингредиента:** Проверка открытия модального окна с деталями ингредиента при клике и его последующего закрытия по нажатию на крестик.
* **Логика корзины:** Drag-and-drop перетаскивание ингредиента в заказ и валидация увеличения счётчика добавленного ингредиента.

### 2. Функциональность раздела «Лента заказов»
* **Счётчики статистики:** Проверка динамического увеличения счётчиков «Выполнено за всё время» и «Выполнено за сегодня» при оформлении нового заказа.
* **Бизнес-логика статусов:** Проверка того, что после успешного завершения заказа его сгенерированный номер корректно отображается в блоке «В работе».
## 💻 Локальный запуск проекта

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd название_репозитория
```

### 2. Настройка виртуального окружения и установка зависимостей
```bash
# Создание виртуального окружения
python -m venv venv

# Активация (для Windows)
venv\Scripts\activate

# Активация (для macOS/Linux)
source venv/bin/activate

# Установка необходимых библиотек
pip install -r requirements.txt
```
*(При необходимости создайте файл `requirements.txt` со следующим содержимым: `selenium`, `pytest`, `allure-pytest`)*

### 3. Запуск тестов
По умолчанию настроена **кроссбраузерность** с помощью параметризации фикстур. Тесты автоматически последовательно запустятся в **Google Chrome** и **Mozilla Firefox**.

Для запуска тестов и генерации сырых данных отчёта в папку `allure-results`:
```bash
pytest --alluredir=allure-results
```

## 📊 Генерация и просмотр Allure-отчётов

Для того чтобы сгенерировать графический отчёт из собранных результатов и автоматически открыть его в вашем браузере по умолчанию, выполните:

```bash
allure serve allure-results
```
*Примечание: Для корректной работы команды `allure` на вашем компьютере должен быть установлен Allure CLI (через Homebrew для macOS или Scoop/прямую установку переменных окружения для Windows).*

При падении любого теста в отчёт автоматически прикрепляется скриншот экрана на момент ошибки (реализовано в `conftest.py`).
